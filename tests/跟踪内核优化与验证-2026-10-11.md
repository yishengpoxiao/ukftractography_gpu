# 跟踪内核优化与验证（2026-10-11）

本轮直接优化 GPU 跟踪循环中的 sigma 点生成和滤波更新，承接上一轮记录传输优化。单卡全脑 Simple2T 混合精度的 GPU waves 从约 19.9 s 降至约 15.9 s，减少约 20%。精度分工、停止条件、记录时机和逐项求和顺序保持不变。本轮验证的 GPU 输出与优化前逐数组完全相等，**不代表已经解决与 CPU 严格对照的既有失败**。

## 实现

仅修改生产源码 `ukf/gpu/gpu_kernels.cu` 的两个计算阶段，共用这些阶段的 12 个模型均经过回归：

1. Cholesky 改为块内并行、原位下三角分解。独立矩阵元素并行计算，各元素仍按原来的升序 k 接收更新；上三角保持零。删除线程 0 的局部 n×n 工作数组，避免串行计算整个工作矩阵。
2. 更新内核先完成需要 Pxz 的残差，再复用该临时空间缓存 Ht×R。信息矩阵和信息向量共用已舍入的乘积，减少重复 FP64 乘法；后续完整 2G 求和顺序不变，不增加设备缓冲。

本轮没有改动源配置文件。较大更新线程块（64/128）和每 8 步压紧活动列表没有显示有用的收益，均已撤回；最终仍为 32 线程更新块、逐步停止检查和逐步活动列表压紧。没有保留实验调节环境变量。

## 性能

验证目录：`/data/yijie/ukf-GPU/validation/tracking-2026-10-11/`。固定全脑输入及参数，288774 个半纤维种子，Simple2T 混合精度，CPU 16 线程，单张 RTX 4090（物理 GPU 0）。全部启用相同 `UKF_GPU_PROFILE=1` 诊断。优化前库、可执行文件和源码在 `before/`；原库复测通过 LD_LIBRARY_PATH 明确选择该库，已用 ldd 确认。

| 指标 | 原库复测 | 最终版本 | 最终版本再次运行 |
|---|---:|---:|---:|
| GPU waves 合计 | 19.886 s | 15.933 s | 15.943 s |
| 跟踪阶段（含传输、主机解包等） | 24.0414 s | 19.9317 s | 20.2380 s |
| 端到端墙钟 | 42.03 s | 38.53 s | 41.56 s |
| 输入读取 | 7.22444 s | 7.30784 s | 10.3095 s |

GPU waves 减少 **19.88%**，约 **1.25×**；跟踪阶段减少约 **16–17%**。总墙钟受到共享机器输入读取等波动影响，第一组降低约 8.3%，不宣称为稳定端到端加速比。第一批抽样 sigma 时间约 33.4→8.1 ms，update 约 109.4→97.2 ms；这些是每 64 步抽样的事件累计，不能作为完整阶段耗时。

中间版本仅缓存 Ht×R 时，waves 为 18.619 s；加并行 Cholesky 后进一步降低。原始日志、VTK、实验源码和 `timings.json` 均保留。

另测已有双卡调度路径，仅暴露空闲物理 GPU 0/1，使用 `--gpuDevice -1`：跟踪 **11.4701 s**、总墙钟 **29.88 s**。相对最终单卡第一次运行，跟踪约 **1.74×**。这是 Simple2T 混合精度全脑单次测量，不能推及全部模型的多卡精度或速度；双卡同时运行的 waves 日志不能相加解释为墙钟。

## 验证及精度限制

- `all-models.log`：12 模型 × FP64/混合入口，共 24 组；坐标、连接和全部状态、协方差、模型记录数组均与上一轮 GPU 输出严格相等。
- `final-identical.log`、`final-repeat-identical.log`：最终两次全脑输出的全部数组与本轮原库复测相等。`cholesky-identical.log`、`scaled-identical.log` 记录中间版本的同类检查。
- `dual-identical.log`：本轮双卡全脑输出与原单卡库输出全部数组相等。
- `branches-identical.log`：分支生成和第二轮追踪后的全部输出与上一轮相等。
- `model-final.log`：12 个模型各连续 20 步 CPU/GPU 内核对拍通过，最大状态误差约 6.59e-12、协方差误差约 9.37e-14，包含 Watson 边界检查。
- `l1-final.log`：Simple1T/2T × FP64/混合精度 × 40/800 步共 8 组通过，包括尾批、协方差、记录数和边界哨兵。
- `model-{memcheck,racecheck,synccheck}.log`、`l1-{memcheck,racecheck,synccheck}.log`：CUDA 内存、竞争、同步检查均通过，零错误、零竞争警告；memcheck 开启完整泄漏检查，零显存泄漏。检查覆盖合成任务，并非全脑 sanitizer 运行。
- `strict-cpu-audit.json`：24 组小用例直接对照已有 CPU 输出，14 组满足逐纤维点数一致且位置欧氏距离 ≤0.001 mm，10 组仍失败，与优化前一致。Full2T 的几何通过不能替代协方差等记录验收。
- `branches-strict.log`：CPU 严格分支对照仍失败，38 条纤维中 1 条点数不同，保留失败结果。

Full Tensor、双张量 FreeWater、长 NODDI2F、退化 Simple3T、分支及全脑与 CPU 的既有精度限制没有因提速解除，参见 [严格精度验收](严格精度验收-2026-10-11.md)。对原本保留 FP64 的模型，本轮没有降低精度。

## 复现和部署

```bash
cd /data/yijie/ukf-GPU/ukftractography
export LD_LIBRARY_PATH=/data/yijie/miniconda3/envs/ukf-gpu/lib:$LD_LIBRARY_PATH
CMAKE=/data/yijie/miniconda3/bin/cmake bash scripts/build_gpu_all_models.sh
CUDA_VISIBLE_DEVICES=1 /data/yijie/miniconda3/envs/tractography/bin/python \
  tests/validate_record_transfer.py \
  --reference ../validation/transfer-2026-10-11/all-models \
  --output /tmp/ukf-tracking-regression

CUDA_VISIBLE_DEVICES=1 NVCC=/data/yijie/miniconda3/envs/ukf-gpu/bin/nvcc \
  bash tests/validate_fp32.sh /tmp/ukf-tracking-l1
```
