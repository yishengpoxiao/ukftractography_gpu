# GPU 速度优化与验证（2026-10-10）

本次在 [FP32 修复版本](FP32修复与验证-2026-10-10.md) 上继续优化。精度分工不变：插值和 sigma 信号预测使用 FP32，滤波核心使用 FP64；`--gpuPrecision 0` 仍为 FP64。

## 实测结果

同一台共享机器、单卡 GPU 0、相同输入和参数，混合精度全脑 2T，288,774 个半纤维种子，输出 134,450 条纤维。以下为端到端单次测量，包含输入、初始化和 VTK 输出。

| 项目 | 本轮优化前 | 最终版本 |
|---|---:|---:|
| 总墙钟时间 | 66.32 s | 43.53 s |
| 追踪阶段 | 41.9633 s | 25.8241 s |
| VTK 输出 | 8.66375 s | 2.8352 s |
| 主机峰值内存 | 16,512,796 KiB | 13,014,940 KiB |

总耗时降低 **34.36%**，加速 **1.52 倍**，峰值内存降低约 **21.2%**。这些结果是同参数顺序运行的单次观测，不是多次测量的稳定性能保证；两次均开启诊断 `UKF_GPU_PROFILE=1`。日志为 `validation/speed-2026-10-10/profile-before.log`、`pages-final.log`。

## 已实现的优化

1. 利用信号的正负梯度对称性。`NrrdData` 构造 G 个梯度及其相反向量，两半 b 值和观测信号相同。H 预测、观测中心化、互协方差等只计算前 G 项，再复制对应后半；最终求和仍按完整 2G 的原顺序进行，避免改变舍入路径。此约束已写入 GPU API。
2. 1T/2T 更新和 sigma 内核按状态维度 5/10 模板实例化，缩小局部数组；共享中心化状态及其加权结果，减少重复算术。波次内核使用 32 线程块，H 内核保留 256 线程块。线程块调整本身没有证明端到端收益，不单独宣称加速。
3. 未启用的 NMSE、FA、trace 不分配主机记录区、不下载；有效输出缓冲通过并行触页准备，避免串行清零所有数值。最终主机 staging 从 3.743 s 降到 0.537 s。设备侧这些可选记录缓冲仍保留。
4. 按记录数预留纤维数组、原位构造状态和协方差，最多 8 个主机线程并行解包独立纤维。
5. VTK 点坐标一次分配后按纤维区间并行填充；连接数组预分配并复用 ID 缓冲，去掉逐纤维 vtkLine 构造及反复分配。坐标类型和转换公式保持一致。
6. 增加可选诊断：`UKF_GPU_PROFILE=1` 输出主机 staging/unpack、每批 waves/download 墙钟和抽样内核事件。内核事件每 64 步抽样，不能直接视为完整阶段耗时。

## 复现

```bash
cd /data/yijie/ukf-GPU/ukftractography
export LD_LIBRARY_PATH=/data/yijie/miniconda3/envs/ukf-gpu/lib:$LD_LIBRARY_PATH
/usr/bin/time -v ../bin/UKFTractography_gpu \
  --dwiFile UKFTractography/Data/Input/dwi.nhdr \
  --maskFile UKFTractography/Data/Input/dwi-mask.nhdr \
  --seedsPerVoxel 1 --numTensor 2 --numThreads 16 \
  --stoppingFA 0.10 --stoppingThreshold 0.05 --Qm 0.001 --Ql 10 --Rs 0.015 \
  --minBranchingAngle 0 --maxBranchingAngle 0 \
  --useGPU --gpuDevice 0 --gpuPrecision 1 --tracts /tmp/full2T-speed.vtk

/data/yijie/miniconda3/envs/tractography/bin/python tests/assert_fiber_data.py \
  ../validation/speed-2026-10-10/profile-before.vtk \
  ../validation/speed-2026-10-10/pages-final.vtk
```

可在运行命令前加 `UKF_GPU_PROFILE=1` 收集诊断。CLI 位于 `bin/UKFTractography_gpu`，配套共享库位于 `build-gpu/lib/libukf_gpu.so`；校验值见验证目录的 `delivered-binaries.sha256`。原版二进制、源文件备份和各次实验产物均保留在验证目录。本次未修改配置文件。
